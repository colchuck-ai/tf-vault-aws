# tf-vault-aws

A set of lightweight, production-grade Docker images for Infrastructure-as-Code workflows.  
Includes core CLI tools used in cloud automation pipelines:

- **Terraform**
- **Vault**
- **AWS CLI v2**
- **git**
- **jq**

Two variants are provided:

| Variant  | Base Image | Size    | Best For                        |
| -------- | ---------- | ------- | ------------------------------- |
| `alpine` | Alpine     | ~100 MB | Fast CI jobs, minimal footprint |

|
